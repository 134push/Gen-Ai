## 📘 1. Python-len (Python Fundamentals)

Comprehensive topic-wise practice covering Python from foundational to object-oriented programming:

| Section | Topic | Description |
| :--- | :--- | :--- |
| **01 - 04** | **Basics & Operators** | Variables, Data Types, Type Casting, Arithmetic & Logical Operators |
| **05 - 07** | **Control Flow** | Input/Output formatting, Conditional Statements (`if-else`), Loops (`for`, `while`) |
| **08 - 12** | **Data Structures** | Strings, Lists, Tuples, Sets, and Dictionaries |
| **13 - 15** | **Functions & Files** | User-defined functions, Exception / Error Handling, File I/O operations |
| **16 - 18** | **Modular & OOP** | Custom Modules, Packages, and Object-Oriented Programming (Classes, Encapsulation) |

## 🛠️ 2. Projects & Assignments

Practical hands-on programs and academic assignments:

### 🎮 Mini Projects
- **Hangman Game** (`hangman.py` / `1hangman.ipynb`) – Classic word-guessing game.
- **Caesar Cipher** (`caesar_cipher.py`) – Text encryption and decryption utility.
- **Silent Auction / Bidder** (`bidder.py`) – Blind bidding console application.
- **Grading Program** (`grad.py`) – Student score evaluation and grading system.
- **Life in Weeks** (`life_in_weaks.py`) – Age and time calculation utility.
- **Love Calculator** (`love_cal.py`) – Fun compatibility testing script.

### 📚 Tutedude Assignments
- **Assignment 1:** Python basics, variables, and expressions.
- **Assignment 2:** Data structures, lists, and operations.
- **Assignment 3:** Conditionals, iterations, and logic building.
- **Assignment 4:** File handling operations, sales analytics, and discount report generators.
- **Assignment 6:** Exception & Error handling (`try`, `except`, `finally`, custom exceptions).
- **Modules Assignment:** Python modules (`math_utils`, `string_utils`) and packages (`shop_packages` with `billing` & `discount`).
